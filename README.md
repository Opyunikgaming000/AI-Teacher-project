# AI-Teacher-project

## Simple 2D Shooter (pygame)

This repository now includes a small playable 2D shooter game.

### Requirements
- Python 3
- `pygame` (`pip install pygame`)

### Run
```bash
python main.py
```

### Controls
- Move: Arrow keys or `WASD`
- Shoot: `Space`
- Restart after game over: `R`

### Objective
Shoot enemies to increase your score. If an enemy collides with your ship, the game ends.
